# TvLauncher для Sony KD-55XF9005

Свой лаунчер для Android TV в стиле Apple TV.

## Что умеет
- Крупные часы и дата по центру экрана
- Входы HDMI и USB в левом верхнем углу
- Значки: приложения, Wi-Fi, таймеры Sony, обои, настройки, экран Sony
- Избранное: ровно 5 плиток в ряд, листается стрелками
- Выбранная плитка пульсирует, со стеклянным бликом
- Долгое нажатие OK: меню из матового стекла (открыть, переместить, убрать, добавить)
- 50 встроенных обоев: минимализм, Mac, Windows, времена года, природа, города
- Цвет меню подстраивается под обои
- Переключение между TvLauncher и стандартным экраном Sony

## Сборка
1. Загрузить `tvlauncher-src.zip` в репозиторий
2. Actions соберёт APK автоматически
3. Скачать артефакт `TvLauncher-apk` и установить на телевизор
