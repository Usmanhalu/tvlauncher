# BraviaGlow v0.2 — эксперимент для штатного Sony Android TV Home

BraviaGlow **НЕ является лаунчером** и не заменяет Sony Android TV Home.
Он подключает службу специальных возможностей, которая наблюдает события
перемещения фокуса и показывает короткий цветной полупрозрачный градиент
поверх пустых областей штатного главного экрана.

## Установка на телевизор

1. Установите собранный APK BraviaGlow-debug.apk через файловый менеджер.
2. Откройте BraviaGlow из списка приложений.
3. Нажмите «Включить ... в специальных возможностях».
4. В настройках Sony найдите BraviaGlow и включите службу.
5. Нажмите HOME и перемещайтесь по приложениям стрелками пульта.
6. Если цвет не меняется, снова откройте BraviaGlow и нажмите «Обновить статус».
   По строке «Последнее событие» можно понять, читается ли название приложения.

## Ограничения

- Фон рисуется **поверх**, а не внутри штатного лаунчера. Android TV Home
  не даёт стороннему APK управлять собственным фоном.
- Некоторые версии Google TV не отдают через Accessibility названия иконок.
  В таком случае цвет не сможет автоматически меняться на каждой иконке.
- При выходе из штатного Sony Home служба пытается скрыть прозрачный слой.
- Эффект не влияет на пульт, не перехватывает клики, не подменяет системный
  HOME, не требует root, не меняет системные APK.
- Требуется явное разрешение пользователя на специальную возможность.
  Служба может читать элементы текущего интерфейса, поэтому включайте
  её только если понимаете, на что даёте разрешение.
- Сетевых разрешений нет: данные никуда не отправляются.

## Как полностью убрать

В настройках Sony: Специальные возможности → BraviaGlow → Выкл.
Затем удалите BraviaGlow как обычное приложение. Штатный лаунчер не менялся.

## Сборка

Android Gradle Plugin 8.4.2, Gradle 8.7, Java 17, compileSdk 35, minSdk 23.
Запуск: `gradle -p braviaglow :app:assembleDebug`

Это **экспериментальный тест**, фактическая совместимость со Sony BRAVIA ATV3
ещё не проверена на живом телевизоре.

## v0.2 исправления

- Вместо двух обрезанных верхней/нижней полос используется один непрерывный полноэкранный радиальный градиент.
- Цвет мягче, без резкой горизонтальной границы, эффект остаётся поверх оригинального Sony Home.
- Для установки v0.2 после v0.1 может понадобиться удалить старую версию: тестовые APK GitHub Actions подписаны разными временными debug-ключами. До удаления выключите старую службу специальных возможностей; после установки снова включите её.
- Заводской Sony Android TV Home не удаляется и не заменяется.

## v0.3: безопасность и диагностика

- По умолчанию эффект выключен; включить его можно только после явного подтверждения в BraviaGlow.
- Не создаёт оверлей при запуске службы; рисует только после распознавания приложения на Sony Home и удаляет окно при выходе.
- Убрана кнопка открытия специальных возможностей через Intent, не поддерживаемый на Sony ATV3.
- Нет перехвата нажатий, глобальных действий и автоматической настройки ADB.
- Названия приложений собираются из Accessibility и сопоставляются с установленными TV-программами. Если Sony не отправляет фокус, автоматическая подсветка недоступна.
- Экспериментальный режим может всё равно влиять на OK из-за поведения Accessibility в прошивке Sony: при первых симптомах выключить режим и системную службу.
- Тестовый APK подписан случайным GitHub Actions debug-ключом. Для установки поверх v0.2 может потребоваться удаление старой версии без затрагивания Sony Home.
